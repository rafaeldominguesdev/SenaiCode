## ▶️ Como executar

**Projetos Java** — abra a pasta do semestre como workspace no Eclipse (ou importe o projeto desejado) e execute a classe que contém o método `main`.

```bash
# Alternativa via terminal, dentro da pasta do projeto
javac -d bin src/*.java
java -cp bin NomeDaClasse
```

**Páginas HTML** — basta abrir o arquivo `index.html` da pasta desejada no navegador, ou usar a extensão *Live Server* no VS Code.
